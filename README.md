# Online Courses Subscription Platform (Backend)

## Overview
This project is the backend API for an online courses subscription platform, where users can:
- Subscribe to various plans.
- Gain access to courses based on their active subscriptions.
- Automatically lose access when their subscription expires.

### Key Features:
- Users can subscribe to plans such as **Monthly**, **Quarterly**, **Yearly**.
- Subscription status management: **Active**, **Cancelled**, **Expired**.
- Access to courses is granted based on active subscription status.
- Automatic revocation of course access when subscriptions expire.
